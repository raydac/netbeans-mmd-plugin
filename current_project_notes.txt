## 2. Architecture & Technical Discoveries
- Do not put `<fileType>` as a root `<idea-plugin>` child. 222 PluginManager treats that as `Unknown element: fileType` (`XmlReader.readRootElementChild`). It must live under `<extensions defaultExtensionNs="com.intellij">`.
- `fileType` attributes that exist on 222: `name`, `implementationClass`, `fieldName`, `language`, `extensions`. `name` must match `FileType.getName()`, `language` must match `MMLanguage` id `NBMindMap`.
- `MindMapFileType` constructor is private; `fieldName="INSTANCE"` is required.
- Latest IntelliJ New File popup lists file types from the declarative EP. `FileTypeFactory` is deprecated and ignored or unloaded there, so MMD vanished from New while the editor could still open existing files.
- `CreateFileFromTemplateAction` on 222: constructor `(text, description, icon)`, `buildDialog(Project, PsiDirectory, Builder)`, `getActionName(...)`. `createFile` resolves the template via `getInternalTemplate`, which also falls back to Files-category templates.
- Panel shortcuts are KeyListener + `MindMapPanelConfig` maps, not panel ActionMap/InputMap. Host IDEs must not assume Swing Action registration on the panel.
- Title editor Enter end-edit must use keyPressed/keyReleased (`getKeyCode()`); KEY_TYPED has `VK_UNDEFINED` so typed-path end-edit was dead.
- Shift+Enter next-line intentionally handled in both typed and released for RUS layout under Linux/IDEA.
- scia-reto: tree model notifications already use `Utils.safeSwingCall`; subtree load mutates `children` off EDT but listeners are notified on EDT via `notifyProjectStateChanged` / `invokeLater` fireNotifySubtreeChanged.
- scia-reto: `MindMapPanelConfig.getScaleModifiers()` still uses old `KeyEvent.CTRL_MASK` style — keep `getModifiers()` when matching wheel/scale shortcuts against that config.

## 3. Technical Debt & Refactoring
- Files-category template plus `NewGroup` action can show two "SciaReto Mind Map" entries on older File | New menus. Prefer keeping both over missing the item on the new New File popup.
- No unit tests under `idea-mindmap`.
- `IdeaUtils` still uses reflection for Maven, TransactionGuard, and HTMLEditorProvider to stay on 222.
- Plugin menu wiring (`AbstractExporter`/`AbstractImporter`/`ChangeColorPlugin`/`OptionsPlugin`) still duplicates ExternallyExecutedPlugin listener boilerplate; consolidate later via protected helper on `AbstractPopupMenuItem` without changing public plugin APIs.

## 8. User Advice and Recommendations
- Keep File | New compatibility with latest IntelliJ and with previous versions back to 2022.2.5 (222.4554.10).
- Do not break public APIs of mind-map-swing-panel when cleaning internal Swing action handling.
- Do not break public APIs of mind-map-model (signatures, Serializable UIDs, logger SPI) when fixing internals.
- Restrict scia-reto Swing audits/fixes to the `scia-reto` submodule unless the user widens scope.
- For user-facing fixes and changes, update both root `README.md` (Changelog section) and `changelog.txt`.
